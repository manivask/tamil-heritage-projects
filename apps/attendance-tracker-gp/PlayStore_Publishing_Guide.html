Play Store Publishing Guide

This guide provides the steps to build your APK/AAB and publish the Attendance Tracker GP app to the Google Play Store.

Step 1: Build the Web Project

Ensure your latest changes in app.js, index.html, and style.css are ready.

npm run build  # If you have a build script, otherwise ensure files are in 'www' folder

Step 2: Sync with Capacitor

Update the Android project with your web assets.

npx cap sync android

Step 3: Generate a Signed APK/AAB

Open the android folder in Android Studio.

  • Go to Build > Generate Signed Bundle / APK...
  • Select Android App Bundle (recommended for Play Store) or APK.
  • Create a new Keystore or use an existing one. Keep this safe! You need it for all future updates.
  • Follow the wizard to generate the release file.

Step 4: Google Play Console Setup

Log in to your Google Play Console.

  • Click Create app.
  • Provide App Name, Language, and Category (e.g., Education or Productivity).
  • Complete the App set-up tasks (Privacy Policy, App Access, Content Rating, etc.).
  • Upload your .aab file to the Production track.

Step 5: GitHub Upload

Upload your generic version to GitHub for version control and collaboration.

git init
git add .
git commit -m "Initial commit for generic Attendance Tracker GP"
git remote add origin https://github.com/yourusername/attendance-tracker-gp.git
git push -u origin main
Important: Ensure you have replaced all placeholder branding and icons in the android/app/src/main/res folder before publishing.
